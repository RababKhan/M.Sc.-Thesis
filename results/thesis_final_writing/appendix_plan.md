# Appendix plan (A–K)

The appendices are drafted in `appendices.md`, generated by `tools/build_appendices.py`. Every table in them is
read directly from a frozen CSV or JSON record, and the source file is named under each table. No value was typed by
hand, no experiment was run and the test set was not read. Test accuracies appear only where they are already stored
in the frozen phase summaries that the chapters report.

Length: about 11,200 words of text and tables (1,043 source lines), estimated at 22–30 formatted pages depending on
the template's table font size.

## Decisions

- **Ordering.** The appendices follow the order in which the chapters use them: model → Phase 3 → 4 → 5 → 6 →
  deployment → reproducibility.
- **Statistics.** Every pre-registered comparison is listed with its mean difference, 95% t-CI, Holm-adjusted p, win/loss/tie count and outcome,
  including non-significant and inconclusive ones. This is so that the main text's selection of comparisons can be
  checked.
- **Neutral naming.** Folder names that contain "green" appear only as literal file paths in code formatting. The
  internal criterion name GREEN-SUCCESS is shown once, labelled as an internal file name, and described as the
  "joint deployment-efficiency criterion".
- **No new analysis.** The appendices hold no derived statistic that does not already exist in a frozen file.
- **No test-set use.** No appendix value was computed from the test set during writing. Stored test accuracies are
  copied from frozen summaries.

## Open items (presentation only)

1. **Appendix pointers from the chapters.** No chapter cites an appendix. Adding pointers such as "(full results in
   Appendix B)" would be a chapter-text edit. It is not authorised in this stage and is left for the user to approve
   at template stage.
2. **Landscape pages.** Tables B.2, C.2, D.4, E.2 and F.2 have 8 columns. They will probably need landscape pages
   or a smaller table font in the official template.
3. **Template numbering.** Appendix tables are currently identified by section (e.g. B.2), not by a "Table B.x"
   caption. The final numbering scheme depends on the institutional template.
